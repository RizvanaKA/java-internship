# Java Development Internship – Week 1 Assignments

## Introduction

This repository contains my Week 1 assignments completed as part of the Java Development Internship at WeIntern Pvt Ltd.

## Projects

### 1. Library Management System

A simple Java application used to manage library books.

**Features:**
- Add books
- View all books
- Search for books
- Issue and return books
- Remove books

**Concepts Used:** Classes, Objects, Encapsulation, Constructors, and Collections.

### 2. Banking Application

A simple Java application that performs basic banking operations.

**Features:**
- Deposit money
- Withdraw money
- Check account balance

**Concepts Used:** Classes, Objects, Methods, Conditional Statements, and Exception Handling.

### 3. Java Collections Challenge

A Java application demonstrating the use of Java Collections Framework.

**Features:**
- Add, view, search, update, and remove items using ArrayList
- Store and retrieve student information using HashMap
- Add, remove, and view customers using Queue

**Concepts Used:** ArrayList, HashMap, Queue, and LinkedList.

## Technologies Used

- Java
- Java Collections Framework
- Visual Studio Code 

## How to Run

1. Install the Java Development Kit (JDK).
2. Open the required project folder in the terminal.
3. Navigate to the folder containing the Java source files.
4. Compile the Java files using the javac command.
5. Run the program using the java command.

Example for the Java Collections Challenge:

```bash
javac CollectionsManager.java
javac Main.java
java Main
```

Use the corresponding Java filenames for the other projects.

## Screenshots

Screenshots of the program outputs for each project are included in separate screenshot files.

## Conclusion

These assignments helped me practise Java programming fundamentals, object-oriented programming, and the use of Java Collections.







# Java Development Internship – Week 2 Assignments

## Introduction

This repository contains my Week 2 assignments completed as part of the Java Development Internship at WeIntern Pvt Ltd.

## Projects

### 1. Student Management System

A Java application used to manage student information.

**Features:**
- Add Student
- Display All Students
- Search Student by ID
- Search Student by Name
- Update Student
- Delete Student
- Calculate Average Grade

**Concepts Used:** Classes, Objects, Encapsulation, Constructors, Methods, ArrayList, and Object-Oriented Programming.

### 2. Banking System

A Java application that performs banking operations and manages customer accounts.

**Features:**
- Create Account
- Deposit Money
- Withdraw Money
- Balance Inquiry
- View Account Details
- Transaction History
- Change PIN
- Delete Account

**Concepts Used:** Classes, Objects, Encapsulation, Constructors, Methods, Conditional Statements, and Exception Handling.

### 3. JDBC Integration

A Java application that connects to a MySQL database using JDBC to manage student records.

**Features:**
- Add Student
- View All Students
- Search Student by ID
- Update Student Grade
- Delete Student
- Connect Java application with MySQL database

**Concepts Used:** JDBC, MySQL, CRUD Operations, DAO Pattern, PreparedStatement, Exception Handling, and Maven.

## Technologies Used

- Java
- MySQL
- JDBC 
- Maven
- Visual Studio Code

## How to Run

### Task 1 and Task 2

1. Install the Java Development Kit (JDK).
2. Open the required project folder in the terminal.
3. Navigate to the folder containing the Java source files.
4. Compile the Java files using the `javac` command.
5. Run the program using the `java` command.

Example:

```bash
javac Main.java
java Main
```

Use the corresponding Java filenames for each project.

### Task 3 – JDBC Integration

1. Install the Java Development Kit (JDK) and Maven.
2. Install and start MySQL Server.
3. Create the database and students table using the `task3.sql` file.
4. Configure the database connection details in `DBConnection.java`.
5. Open the Task 3 project folder in the terminal.
6. Compile the project using:

```bash
mvn clean compile
```

7. Run the application using:

```bash
mvn exec:java
```
