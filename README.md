# Java Development Internship – Week 1 Assignments

## Introduction

This repository contains my Week 1 assignments completed as part of the Java Development Internship at WeIntern Pvt Ltd.

## Projects

### 1. Library Management System

A simple Java application used to manage library books.

**Features:**
- Add books
- View all books
- Search for books
- Issue and return books
- Remove books

**Concepts Used:** Classes, Objects, Encapsulation, Constructors, and Collections.

### 2. Banking Application

A simple Java application that performs basic banking operations.

**Features:**
- Deposit money
- Withdraw money
- Check account balance

**Concepts Used:** Classes, Objects, Methods, Conditional Statements, and Exception Handling.

### 3. Java Collections Challenge

A Java application demonstrating the use of Java Collections Framework.

**Features:**
- Add, view, search, update, and remove items using ArrayList
- Store and retrieve student information using HashMap
- Add, remove, and view customers using Queue

**Concepts Used:** ArrayList, HashMap, Queue, and LinkedList.

## Technologies Used

- Java
- Java Collections Framework
- Visual Studio Code 

## How to Run

1. Install the Java Development Kit (JDK).
2. Open the required project folder in the terminal.
3. Navigate to the folder containing the Java source files.
4. Compile the Java files using the javac command.
5. Run the program using the java command.

Example for the Java Collections Challenge:

```bash
javac CollectionsManager.java
javac Main.java
java Main
```

Use the corresponding Java filenames for the other projects.
